## 8. Could the bot hub be built with Claude artifacts? (checked 2026-10-14)

Francis plans to prototype this in his own time. It is not an assigned task. The answer below was checked against the published-artifact capabilities available on 2026-10-14.

**What artifacts can cover**

| Shawn wants | How a shared artifact page does it |
|---|---|
| One UI everyone logs into | A published page shared with the team; it knows who's viewing (`user`), so each person gets their own history |
| Dedicated plumber and lawyer bots | The page calls Claude directly (`sample`); each bot is a saved set of instructions and knowledge in the page's shared database (`db`) |
| A master bot the others "report to" | The master bot gets the specialist bots as tools (`sample` tools), decides which one to ask and combines the answers |
| "improve them together" | Bot instructions and notes live in the shared database; anyone with edit rights updates them and everyone sees the change |
| Not on personal machines | Everything lives on claude.ai |
| Bots that use real data | The page can use the viewer's connectors (`mcp`): Semrush, Slack, Google Drive, Make |

**Where it falls short**
- **Claude only.** Shawn's main reason for Grockbot is access to whichever model leads. An artifact can't match that.
- **Bots only run while someone has the page open.** No background or scheduled work; that would need Claude Code scheduled tasks or similar.
- **No built-in memory.** Each Claude call starts fresh, so the page must store and resend conversation history.
- **Usage counts against each viewer's Claude account,** with a one-time permission prompt per person.
- **Cross-company sharing is unverified.** Artifacts share within one organization plus invited guests; whether that covers 9019s, Mojo, Big Profits and Savvy cleanly is unknown.
- **It's a tool we'd maintain,** not a product with its own admin controls and roadmap.

**Simpler fallback:** Claude Projects on a Team plan already give shared per-vertical bots (instructions plus files) with no build, but no master bot or shared hub.

**Honest pitch to Shawn:** "we can get the shared bot hub you want inside the tools we already pay for, today," not "Claude does everything Grockbot does."
